# Cut Studio

Cut Studio is a Flutter video editor prototype with a desktop editing workspace and a compact mobile layout.

## Run

Install Flutter, generate the platform runners, then run:

```sh
flutter create --platforms web,android,ios .
flutter pub get
flutter run -d chrome
```

Use `flutter run` with an attached Android or iOS device for the mobile layout. The web and mobile runners are generated by Flutter from this source project.

## Current scope

The workspace provides a preview area, video import, a multitrack timeline, clip controls, and an AI edit prompt with quick actions. AI suggestions and export settings currently demonstrate the editing flow; they do not call an AI service or render an exported video. Native video playback, persistent projects, caption generation, audio processing, and video export still need implementation.
